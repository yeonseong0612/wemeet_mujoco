# We-Meet EV 충전 로봇 — Phase 1 결과 보고서

> RGB-D 비전 기반 6DoF 포즈 추정 + IK 제어를 통한 EV 충전 커넥터 자동 삽입 시뮬레이션
> 산학 협력 중간 보고 · 2026.06

## 1. 프로젝트 개요

전기차(EV) 충전 로봇이 카메라로 차량 충전구의 위치·자세를 스스로 인식하고, 로봇 팔을 제어하여 충전 커넥터를 정밀하게 삽입하는 전 과정을 MuJoCo 물리 시뮬레이션 상에서 구현·검증하였다. Phase 1에서는 비전 인식부터 삽입 직전까지의 **인식–제어 파이프라인 정확도**와 **충돌 안전성**을 정량적으로 확보하는 것을 목표로 하였다.

![삽입 시퀀스](outputs/verify_insert.png)
*그림 1. 접근 → 정렬 → 삽입에 이르는 충전 커넥터 삽입 시퀀스 (시뮬레이션)*

### 시스템 구성

| 구성 요소 | 내용 |
|---|---|
| 로봇 팔 | UR10e 6축 매니퓰레이터 |
| 엔드이펙터 | 충전 커넥터(충전건) 일체형 custom EE |
| 비전 센서 | RGB-D 카메라 (Intel RealSense D435 사양: 848×480, FoV 42.5°) |
| 포즈 추정 | FoundationPose (6DoF object pose, OpenCV 규약) |
| 제어 | Damped Least-Squares IK (2단계: 위치 → 자세) |
| 시뮬레이터 | MuJoCo (충돌 물리 포함) |
| 대상 차량 | KIA EV6 충전구 |

## 2. 시뮬레이션 환경 구축

실제 충전 장면을 충실히 재현하기 위해 차량 충전구·충전건 3D 모델, 다중 카메라 구성, 충전구 좌표계를 정의하였다.

### 3D 모델

충전구(Port)와 충전건(Charger)의 실측 mesh를 시뮬레이션에 도입하여, 소켓 결합면과 커넥터 돌출부의 실제 치수를 반영하였다.

![충전건](outputs/gun_alone.png) ![충전구](outputs/port_alone.png)
*그림 2. 충전건(좌)과 차량 충전구(우) 3D 모델*

### 카메라 구성

용도별로 4종의 카메라를 배치하였다. 특히 실운용 입력에는 엔드이펙터에 장착된 **eye-in-hand(EiH)** 카메라를 사용하여, 로봇이 충전구에 접근할수록 더 가까이서 정밀하게 인식하도록 구성하였다.

| 카메라 | 종류 | 용도 |
|---|---|---|
| `cam_eih` | Eye-in-hand (EE 장착) | **FoundationPose 실운용 입력** |
| `cam_port` | 고정 외부 (Eye-to-hand) | 비교 기준(baseline) |
| 스테레오 L/R | 고정 스테레오(baseline 0.12 m) | RGB-D vs 스테레오 비교용 |
| overview | 고정 조망 | 디버깅 뷰 |

![EiH 뷰](outputs/eih_view_test.png)

### 충전구 좌표계

소켓 입구 중심을 기준으로 접근 웨이포인트, 삽입축, 착좌 타겟 등 제어에 필요한 기준점(site)을 충전구 mesh 실측 결합면에 정확히 정의하였다. 모든 포즈 추정 결과는 이 좌표계의 고정 오프셋을 통해 삽입 타겟으로 환산된다.

## 3. 포즈 추정 및 제어 파이프라인

카메라 RGB-D 입력으로부터 충전구 6DoF 포즈를 추정하고, 좌표 변환을 거쳐 IK로 로봇 팔을 삽입 위치까지 이동시키는 전 과정을 구현하였다.

### 전체 흐름

```
RGB-D 입력 → FoundationPose(6DoF 충전구 포즈) → 좌표 변환 → IK(2단계) → 삽입 위치 이동
```

1. **인식** — EiH 카메라의 RGB + Depth 영상을 FoundationPose에 입력하여 카메라 기준 충전구 포즈를 추정한다.
2. **좌표 변환** — 추정 포즈에 충전구 좌표계 오프셋을 적용하여 삽입 타겟을 산출하고, 촬영 시점 카메라 자세를 이용해 월드 좌표로 변환한다.
3. **제어** — 위치 IK로 대략 정렬한 뒤 자세 IK로 정밀 정렬하는 2단계 방식으로 수렴 안정성을 확보한다.

### Depth 노이즈 모델

실제 RealSense D435 센서의 depth 오차 특성을 모사한 노이즈 모델(none / low / medium / high)을 도입하여, 이상적 GT depth가 아닌 **실환경에 가까운 입력**에서의 강건성을 평가하였다. medium 단계가 D435 실측 수준에 해당한다.

## 4. 정량 평가 결과

카메라 종류(외부 고정 vs eye-in-hand)와 노이즈 수준을 조합한 5개 조건(A~E)에 대해 각 N=50회 평가하였다. 핵심 지표는 **삽입 착좌 위치 오차(insert landing)** 이다.

| 조건 | 카메라 | 노이즈 | 포즈 위치오차 (mm) | 포즈 회전오차 (°) | **삽입 착좌오차 (mm)** |
|---|---|---|---|---|---|
| A | 외부 고정 | none | 0.94 | 0.84 | 1.00 |
| **B** | **EiH** | **none** | **0.77** | **0.70** | **0.58** |
| C | EiH | low | 0.90 | 0.77 | 0.74 |
| D | EiH | medium | 0.94 | 0.76 | **0.75** |
| E | EiH | high | 1.01 | 0.70 | 0.80 |

*(N=50, seed=42, 평균값)*

![A~E 비교](outputs/eval_comparison.png)
*그림 5. 조건 A~E 정확도 비교*

![조건B 상세](outputs/eval_B_eih_none.png)
*그림 6. 최우수 조건 B(EiH, 노이즈 없음) 상세 평가 결과*

### 핵심 발견 3가지

1. **Eye-in-hand 전환으로 삽입 정확도 42% 향상** — 외부 고정 카메라(조건 A, 1.00 mm) 대비 eye-in-hand(조건 B, 0.58 mm)로 전환 시 삽입 착좌 오차가 **1.00 mm → 0.58 mm (42% 감소)**. 가까이서 인식할수록 정확도가 향상됨을 확인하였다.

2. **실환경 노이즈에서도 서브밀리미터 정확도 유지** — D435 실측 수준 노이즈(medium, 조건 D)에서도 삽입 오차 **0.75 mm**로, 실제 센서 환경에서 충분한 정밀도를 확보하였다.

3. **회전 오차는 노이즈에 불변** — depth 노이즈 수준(none~high)과 무관하게 회전 오차는 **0.70~0.84°** 범위로 일정하게 유지되었다. 이는 depth 노이즈가 거리(병진) 추정에는 영향을 주지만 자세(회전) 추정은 RGB 형상 정보에 주로 의존하기 때문으로, 노이즈가 **병진 오차에만 작용**함을 시사한다.

## 5. 충돌 검증

삽입 동작이 충전구와 물리적으로 간섭 없이 이루어지는지 검증하기 위해 충돌 물리를 도입하였다.

### 설계 방침

기존 모델은 충전건·충전구가 모두 시각 표현만 있어 충돌을 감지하지 못했다. 충전구 소켓은 구멍이 뚫린 오목 형상이라 mesh를 그대로 쓰면 시뮬레이터가 구멍을 막아버려 삽입 판정이 불가능하다. 이를 해결하기 위해:

- **충전구 소켓 입구**를 8개 기둥으로 이루어진 **링(ring) 형상**으로 근사 — 중앙은 뚫려 있어 정렬된 커넥터는 통과하고, 어긋난 커넥터는 테두리에 닿도록 하였다(안쪽 반지름 21 mm, 커넥터 반지름 20 mm로 1 mm 여유).
- **충전건 tip**에 원통형 충돌 형상을 부여.
- 충돌 감지는 **충전건↔충전구 쌍에만** 적용하여 기존 로봇 동작에는 영향을 주지 않도록 분리하였다.

판정은 접근→삽입 궤적 40스텝을 따라가며 접촉이 발생한 스텝 수(`hit_steps`)로 평가한다.

![충돌 테스트](outputs/collision_test_vis.png)
*그림 7. 4개 케이스 충돌 테스트 (정렬 / 5° 오정렬 / 10° 오정렬 / FP 추정)*

### 4케이스 결과

| 케이스 | 설명 | 접촉 스텝 (hit_steps) | 착좌 오차 | 판정 |
|---|---|---|---|---|
| 1 | 정렬 삽입 (GT 포즈) | **0/40** | 0.02 mm | **PASS** (무접촉 통과) |
| 2 | 5° 오정렬 삽입 | 6/40 | 0.02 mm | CONTACT (간섭 감지) |
| 3 | 10° 오정렬 삽입 | 8/40 | 0.02 mm | CONTACT (간섭 감지) |
| 4 | FP 추정 포즈 삽입 | **0/40** | 0.79 mm | **PASS** (무접촉 통과) |

정렬된 삽입과 실제 FoundationPose 추정 기반 삽입은 모두 무접촉으로 통과하였고, 의도적으로 5°·10° 어긋난 경우에만 간섭이 깨끗이 감지되어 충돌 검증 체계가 올바르게 동작함을 확인하였다.

## 6. 향후 계획

Phase 1에서 인식–제어 파이프라인의 서브밀리미터 정확도와 충돌 안전성을 확보하였다. 다음 단계는 다음과 같다.

### Phase 2 (예정)
- **오정렬 허용 범위 확장** — 현재 10°인 의도적 tilt 범위를 15~20°로 확대하여 강건성 재평가.
- **물리 기반 삽입 시뮬레이션** — 위치제어 actuator를 이용한 quasi-static 삽입으로 실제 접촉력 정량화.
- **RGB-D vs 스테레오 depth 비교** — FastACVNet+ 스테레오 depth와 RGB-D 입력의 정확도 정량 비교 ablation.

### 논문화
- 조건 A~E 비교표 기반 정량 평가 결과 정리.
- "depth 노이즈가 병진 오차에만 영향을 미친다"는 분석 결과 서술.
